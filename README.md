## Quick Network 소개
Quick Network는 대규모 IT 행사에서 참가자 간 네트워킹의 질을 높이고, 의미있는 만남과 비즈니스 협업을 유도하는 서비스입니다. <br>
사용자 정보 기반의 매칭 시스템을 통해 참가자들이 더 빠르고 효과적으로 연결될 수 있도록 지원합니다.<br>
네트워킹 존을 마련하여 행사장의 현장감을 극대화하고, 네트워킹을 더욱 활발하게 유도하는 것을 목적에 두고 있습니다.<br>

## Quick Network의 주요 기능
- 1:1 & 그룹 매칭
    - 참가자의 직무, 관심 분야, 네트워킹 목적을 기반으로 맞춤형 매칭을 지원합니다.
    - 1:1 또는 그룹 매칭 (최대 4인)을 통해 목적에 따른 네트워킹이 가능합니다.
- 테이블 기능
    - 사용자들이 실제 네트워킹을 할 때 사용하는 공간입니다.
    - 네트워킹존의 원활한 운영을 위해 테이블 사용 제한 시간을 30분으로 설정하였습니다.
    - 테이블을 신청하면 테이블이 자동 배정됩니다.
    - 테이블이 만석일 경우, 예약 기능을 제공합니다. 
- 실시간 채팅
    - 참가자들의 일정 조율을 위해 실시간 채팅을 제공합니다.
    - 테이블 QR 촬영 후 채팅방에서 이탈됩니다. 
- 온라인 명함 기능
    - 컨퍼런스 후 네트워킹을 지속하기 위해 온라인 명함 기능을 제공합니다.
    -  QR 코드 스캔만으로 간편하게 명함이 교환 & 저장 됩니다.
    -  네트워킹 종료 후에도 명함 보관함에서 후속 연락이 가능합니다.
